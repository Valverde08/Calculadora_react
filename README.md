# Calculadora React 🧮

Uma aplicação simples de calculadora web, desenvolvida com React e Vite, focada em performance e simplicidade de uso. 

## 🚀 Funcionalidades

A aplicação possui uma interface intuitiva e realiza as quatro operações matemáticas fundamentais de forma reativa:
* **Soma (+)**
* **Subtração (-)**
* **Multiplicação (*)**
* **Divisão (/)**

## 🛠️ Tecnologias Utilizadas

* **[React](https://react.dev/)**: Biblioteca JavaScript para a construção da interface de usuário.
* **[Vite](https://vitejs.dev/)**: Ferramenta de build incrivelmente rápida para desenvolvimento frontend.

## ⚙️ Pré-requisitos

Antes de começar, certifique-se de ter o seguinte instalado em sua máquina:
